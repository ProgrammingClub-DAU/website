# 🚀 CP Club Website: Team Roles & Responsibilities

Welcome to the core development team for the Competitive Programming Club Website! 

We are building a production-grade web application to host our club's leaderboards, member directories, and blogs. 

**Our Tech Stack:**
*   **Frontend:** React, Next.js, Tailwind CSS
*   **Backend:** Java, Spring Boot, PostgreSQL

To ensure we build this efficiently, the project is divided into specialized roles. **Please read through the available roles below and let the Team Leader know which one you want to claim!**

---

## 🎨 Role 1: Frontend UI/UX Architect
* **Focus:** Visuals, Layouts, and the Design System
* **Technologies:** React, Next.js, Tailwind CSS, Framer Motion (optional)
* **What you will do:** You are in charge of making the website look incredible. You will set up the dark-mode CP aesthetic, build the core layout (Navbar, Footer), and design the Home and About pages.
* **Choose this if:** You love CSS, have a great eye for design, and want to ensure the website is fully responsive and looks premium on mobile phones.

## 🧠 Role 2: Frontend Auth & Logic Engineer
* **Focus:** Secure Data Handling, Forms, and Global State
* **Technologies:** React, Zod (Validation), Axios, Zustand (State Management)
* **What you will do:** You are the brains of the frontend. You will build the Login and Registration forms, ensure passwords meet security requirements, and manage the user's logged-in state (JWT tokens) across the app.
* **Choose this if:** You enjoy solving logical puzzles in JavaScript/TypeScript, integrating with backend APIs, and learning how authentication works on the frontend.

## 📊 Role 3: Frontend Data & Dashboards Engineer
* **Focus:** Dynamic Data, Tables, and Profiles
* **Technologies:** React, Next.js, API Fetching
* **What you will do:** You get to build the most exciting user-facing features! You will build the dynamic User Profile dashboard (where users add their Codeforces handles), the Club Members directory, and the live Leaderboard table.
* **Choose this if:** You want to work with real data, build interactive tables, and construct the features that our club members will use the most.

## 🛡️ Role 4: Backend Security & Auth Engineer
* **Focus:** Passwords, JWTs, and API Protection
* **Technologies:** Java, Spring Boot, Spring Security, BCrypt
* **What you will do:** You are the gatekeeper of the backend. You will build the `User` database entity, configure Spring Security, hash passwords, and generate JWT (JSON Web Tokens) so users can log in securely.
* **Choose this if:** You want to learn enterprise-grade backend security. This is a highly sought-after skill in the software engineering industry.

## 📦 Role 5: Backend Data & API Engineer
* **Focus:** Database Queries, Business Logic, and Java Record DTOs
* **Technologies:** Java, Spring Boot, Spring Data JPA (Hibernate), PostgreSQL
* **What you will do:** You are the architect of our data flow. You will build the REST APIs that the frontend uses to fetch users, update profiles, and read blogs. You will ensure the database queries are efficient.
* **Choose this if:** You love backend architecture, designing API routes (GET, POST, PUT), and working directly with databases and JSON data.

## 👑 Role 6: Team Leader & DevOps (CLAIMED)
* **Focus:** Infrastructure, Code Reviews, External APIs
* **Technologies:** Docker, GitHub Actions, Postman, Scheduled Cron Jobs
* **What they do:** The team leader sets up the GitHub repository, manages the Postgres database via Docker, reviews everyone's Pull Requests, and builds the complex Codeforces API synchronization job to power the leaderboard.

---

### How to claim your role:
1. Review the tech stack for the role you want.
2. DM the Team Leader with your top 2 choices.
3. Once roles are assigned, we will have a kickoff meeting to define the API contracts!
